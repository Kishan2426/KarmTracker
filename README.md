# ॐ Karm Tracker (कर्म ट्रैकर)

A lightweight, mindful, offline-first mobile app for tracking Karm, daily virtues, habits, and sacred festivals. Built with React Native & Expo (zero Java / Android Studio required).

---

## 🌟 Key Features

### 1. Today & Karmic Balance (`TodayScreen`)
* **Daily Score Card:** Real-time net balance of **Good Karm (पुण्य)** vs **Bad Karm (अशुभ)** with proportion bars.
* **Trikaya Dimension Balance:** Real-time indicators across **Thought (मानसा)**, **Speech (वाचा)**, and **Action (कर्मणा)**.
* **Routine Habits:** Check off routine habits with live daily streak counts (🔥).
* **Instant Deed Logger (+):** Log spontaneous deeds on the fly with user-defined Good/Bad classification, Thought/Speech/Action dimensions, reflection notes, and quick inspiration prompts.
* **Daily Deeds Timeline:** Review and manage all spontaneous karm recorded throughout the day.

### 2. Vedic Observances & Festivals (`FestivalsScreen`)
* **Curated Calendar:** Major Indian & Vedic festivals (Diwali, Chhath Puja, Kartik Purnima, Maha Shivratri, Holi, Navratri, Janmashtami, Ekadashi, etc.).
* **Live Countdown:** Instant badges displaying days remaining or "TODAY 🌟".
* **Karmic Observances & Pledges (संकल्प):** Pre-suggested deeds (e.g., *Annadanam* / food charity, *Mauna* / silence, meditation) with one-tap pledge commitment.
* **Custom Observance Creator:** Add personal vrats, family rituals, or local observances.

### 3. Insights & Mindfulness (`InsightsScreen`)
* **Trikaya Distribution Visuals:** Clean visual progress split bars for Thought, Speech, and Action.
* **Habit Streaks Leaderboard:** Track discipline and consistency across days.
* **Habit Manager:** Add, customize, or delete routine habits.
* **Zen Theme Switcher:** Seamless toggle between **Dark Zen** (deep meditative dark) and **Warm Sand** (light mode).
* **Evening Reflection Alert:** Optional mindful inquiry reminder.

## 🚀 How to Run the App

### Step 1: Install Dependencies
Open your terminal in this directory and run:
```bash
npm install
```

### Step 2: Start the Expo Development Server
```bash
npx expo start
```

### Step 3: View on your Mobile Phone
1. Open the **Expo Go** app on your phone:
   * **Android:** Open Expo Go and tap **Scan QR code**.
   * **iOS:** Open the default **Camera** app and scan the QR code displayed in your terminal.
2. The app will bundle and open directly on your device.
